# study-log

공부하면서 정리한 노트를 모아 두는 레포.

```
llm/               LLM 학습 노트 (사내 데이터 질의 사례 등)
data-analytics/    분석 케이스, 방법론
coding-test/       SQL 패턴, 치트시트, 연습 문제 풀이
cv/                COCO panoptic 포맷, MediaPipe 합성
```

- SQL 연습은 [하루쿼리](https://sql-jd-trainer.vercel.app)에서 한다
